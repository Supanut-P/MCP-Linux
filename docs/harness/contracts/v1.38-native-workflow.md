# v1.38 native workflow contract

Status: implementation started after independent v1.37 verification closure.

## Goal and approved scope

Deliver validated task contracts, deterministic role prompts, bounded handoffs,
independent QA report preparation, and a milestone report. Native Codex
subagents execute the work from the calling session; MCP prepares coordination
data and does not invoke desktop collaboration APIs or silently launch CLI.

The first product surface is additive READ-only `workflow_plan`. It returns
`dispatch: caller_native`, `executionStarted: false`, a normalized contract,
and requested role presets. Do not expose inert execution/resume endpoints.
Existing `codex_run` calls retain their opt-in permission checks and behavior.
SQLite execution state, context fingerprints, skill provenance, model
capability preflight and stronger evidence verification remain assigned to
their later milestones.

## Implementation tasks

1. Worker: pure contract/prompt/handoff/report helpers in `packages/codex`,
   plus a registered-workspace planning service in `packages/application`.
2. Lead: additive MCP schema/tool and headless wiring; compatibility/catalog,
   development guide, and version metadata.
3. Native proof: reproduce and repair the existing version synchronizer's
   failure to update current README release-asset references, using a worker
   task contract and independent QA. Operate on a disposable fixture for script
   verification; preserve historical release references.
4. Independent QA: inspect scope, changed source and focused verification;
   route failures back within the bounded retry policy.

## Verification and stop conditions

Focused tests must cover malformed/oversized inputs, literal relative file
scope, mandatory stop instructions, deterministic role prompts, 2 KiB UTF-8
handoffs, independent reviewer identity, missing workspace, symlink escape,
and abort-before/after preparation. Preparation must launch no processes or
write workspace files. Requested model presets do not prove provider support.

Before closing v1.38, run full source, integration, packaging, release,
catalog and frozen v1 compatibility gates, build source-bound Ubuntu artifacts,
and run installed STDIO/HTTP and package lifecycle acceptance. Record actual
native bug-fix worker/QA evidence and exact source/diff/command/artifact
references. Do not begin v1.39 before those gates pass.

One writer per scope, at most four total agents and delegation depth one.
Worker uses Luna medium with at most two attempts, then one Sol attempt before
contract review. Worker context target 32 KiB, QA 64 KiB, handoff 2 KiB; safety
instructions stay intact. Stop on necessary external approval, unavailable
provider, scope change, or exhausted attempts. No branches, root commits,
pushes, publication, credential changes or global plugin installation.

# v1.49 evidence-linked diagnosis

v1.48 verification is closed. Add `diagnosis record/get`, preserving incident
collection/output and all frozen v1 contracts. No model orchestration, remote
probes, deployment, commands or local patch execution are added. Further evidence
uses an explicit caller request to existing `incident collect` within registered
scope. v1.50 will separately prepare a local fix task.

Record: diagnosis ID, registered workspace ID, 1–8 hypotheses and 1–8 proposed
fix steps. A hypothesis contains ID, statement, caller-asserted low/medium/high
confidence, rationale, bounded assumptions/unknowns and supporting/contradicting
references `{incidentId,sequence,hash}`. Each hypothesis cites at least one row;
at most 32 distinct refs from eight incidents. Fix steps cite hypothesis IDs and
contain only description and verification prose. Caller prose is interpretation,
never a server-verified fact; omit secrets. No regex can prove prose secret-free.

Resolve through a validated incident access helper under the same actor/owner,
not public-page scraping or unvalidated repository reads. Require terminal
incident collection, matching workspace and row hashes. Expired collection can
project interrupted but cannot replay. Pin incident request/header hashes,
workspace/host registration fingerprints, source and observation time. Derive
historical facts only from validated metadata projections. Retain gaps,
truncation/unavailable and missing-source counts. Incomplete support requires
an explicit unknown explanation; confidence remains caller-asserted, not a
calibrated probability or automatic execution permission.

Immutable records bind owner, ID, request fingerprint, document and creation time
with a canonical hash. Exact-input repeat reads the original record; changed ID
reuse fails. SQLite migration 017 adds one table, 32 records/owner, 256 global,
32 KiB document, bounded SQL fields and strict corruption/hash checks. No automatic
updates, deletions, retries, task dispatch or provider calls. Older binaries ignore
the new table. Current READ/WRITE policy for record, READ for get, post-await
permission checks and one 60-second deadline including evidence/registry reads.

Get revalidates pinned source references and current registrations. Report each
support as current/stale/unavailable separately from historical caller text and
facts. Missing, changed, partial or truncated evidence never proves an incident
cause. A changed historical source must not become fresh support. Ownership is
single-user metadata isolation, not tenant/human authentication.

Verify reference/hash/owner/workspace mismatch, collecting rejection, partial
support with unknowns, registration/source replacement, immutable restart and
idempotency, bounded hung reads/policy revocation, malformed/quota state,
source-only facts, nonexecuting fix proposals and unchanged incident behavior.
Full local, Ubuntu/package, installed STDIO/HTTP/lifecycle/native gates must close
before v1.50. Use fresh bounded storage/contract workers and independent Sol QA;
one writer per file, no dependency/environment changes or nested delegation.

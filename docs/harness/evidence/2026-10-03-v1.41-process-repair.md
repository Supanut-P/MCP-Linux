The parent-first Linux cancellation regression now passes. The
[source receipt](2026-10-03-v1.41-process-repair.json) verifies **15 exact source
and configuration hashes** against the disposable VM lab and binds the retained
focused log. No installed package or accepted v1.40 snapshot was overwritten.

Linux process tests: **25 passed / 0 failed**, exit 0. Windows Codex/process/
application focused tests: **59 passed / 2 platform skips**, exit 0. Typecheck
and scoped ESLint passed. Independent Sol review approved the process repair
with no remaining material source findings; execution was lead-reported.

Owned leader PID/start time is captured at spawn. Bounded `/proc` metadata
observations retain member PID/start time/group/session only while the original
leader matches before and after the scan. A matching survivor is required after
leader exit. Ownership is rechecked before each TERM/KILL; replacement, unreadable
metadata, exhausted bounds and unknown ownership prevent signaling. An empty
snapshot alone cannot prove absence: a second group probe handles disappearance
during observation. Two stable observations of no executing members permit zombie
completion without claiming the group is absent. Samplers stop on parent exit,
error or stop attempt. Failed verification returns bounded errors and leaves the
owned handle available for an explicit retry.

The regression fixture now awaits its asynchronous execution-state check and
revalidates child identity before cleanup. Original failures and diagnosis logs
are retained separately. New negative tests cover short-lived exited children,
reused survivor identities, incomplete observations, changed ownership before
KILL and bounded failed-stop recovery.

This is ordinary-process observational evidence. `/proc` scans and validation to
signal operations are not atomic kernel containment; deliberate concurrent
fork/group moves and escaping process groups are outside the proof. Aggregate
sampling CPU is not load-tested. The scanner bounds each observation to 8192
directory entries, 256 matching members, 4096 stat bytes and 100 ms; it reads no
environment or command contents.

# v1.45 native Windows benchmark: experimental goal missed

The [machine receipt](2026-10-03-v1.45-native-benchmark.json) binds 57 retained
artifacts and the source inputs. Six frozen source/acceptance pairs produced
12 variant runs and 18 actual role invocations through the already logged-in
Windows Codex CLI 0.146.0. Effective configuration was inspected first; all
calls were read-only, integrations disabled and no tools invoked. Available
explicit overrides were gpt-5.6-sol and gpt-5.6-luna at low effort. This does
not verify default gpt-6 aliases or native Linux authentication.

| Measurement | Single agent | Routed roles |
| --- | ---: | ---: |
| Returned-answer fixture acceptance | 4/6 | 4/6 |
| All-role input + output tokens | 115,332 | 208,472 |
| Median fixture tokens | 19,217 | 34,673.5 |
| Median explicit context bytes | 8,676 | 1,243 |
| Sum invocation latency (ms) | 45,538 | 95,048 |
| Observed tool calls / declared retries | 0 / 0 | 0 / 0 |

Median tokens increased **80.43%**, while explicit context bytes decreased
**85.67%**. Both variants retain their two strict answer/format failures. There
was no measured acceptance regression or safety failure. The experimental 25%
token reduction objective is **missed**. Cached input and reasoning subsets are
not added twice. These are actual log-derived tokens, not estimates from bytes;
they are not authenticated billing or account-limit measurements.

Separate role calls repeat CLI harness context, which dominates these small
fixtures. The routing decision is to keep fully deterministic small tasks with
one Lead and checks. Stateful/security changes retain independent QA. The
original expanded topology and all failed outcomes remain in the comparison;
no roles were silently removed or provider calls repeated to improve the result.

The first helper path and effective-config errors occurred before model
execution and remain recorded. The first report rejected current five-field
usage; its null totals remain historical. After a regression-tested parser
repair, the same unmodified raw logs produced the complete final report.

This is a microbenchmark of returned answers using synthetic reviewable source
and unrelated archived context. String/format matching does not prove executable
patch correctness, real incident collection, recovery execution, physical
independent authorship or overall production success. Context bytes exclude
hidden/system and reasoning context. Timing, requested models and verdicts are
caller-attested with retained deterministic checks. Publication is unapproved;
Ubuntu/package closure and final v2 provider readiness are separate gates.

# Release notes

Version-specific release notes live here so the repository root stays focused
on the product source and operator guides.

- [`VERSION_HISTORY.md`](../../VERSION_HISTORY.md) is the semantic-version index.
- Files use the short form `vX.Y.Z.md` and are ordered by version, not by file
  creation time.
- Downloadable packages and checksums remain attached to the matching GitHub
  release; this directory is the durable, reviewable release-note archive.

The project is Linux-only. Windows desktop milestones and upstream attribution
history are not release notes for this product.

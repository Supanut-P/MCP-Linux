# Baitonghub-Linux-mcp v1.37.0

v1.37 adds a bounded read-only journal view across explicitly registered SSH
hosts.

## Added

- `remote_fleet` now supports `operation: "journal"`.
- Each request accepts only registered host IDs, an optional validated systemd
  unit, and `lines` from 1 to 1,000.
- The runtime reuses the pinned `remote_host` journal provider, keeps at most
  four sessions in flight, caps each host at 256 KiB, and returns sanitized
  partial results with bounded timeouts.
- Credential-shaped fields are redacted from returned log text and audit data.

## Safety and compatibility

- The operation is read-only and does not add remote shell, filesystem, process,
  credential, or mutation authority.
- Raw journal queries, shell fragments, unregistered hosts, and unvalidated unit
  names are not accepted.
- Existing v1 tool names and permissions remain additive and compatible.
- The seven-day soak remains waived; this release makes no production-soak
  claim.

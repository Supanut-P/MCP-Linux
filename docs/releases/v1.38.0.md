# v1.38.0 — native workflow preparation

Status: source candidate; full Ubuntu/package acceptance is pending.

Adds READ-only `workflow_plan` for validated task contracts and deterministic
role prompts inside registered workspaces. The caller dispatches native Codex
workers and independent QA. Preparation never executes commands, creates
workflow state, validates provider availability, or grants permissions.

Contract helpers reject malformed, sparse and over-budget inputs; preserve
stop instructions; bound UTF-8 handoffs to 2 KiB; and distinguish caller-supplied
QA reports from independently verified evidence. Registered-root guards,
secret-path policy, symlink escape checks and preparation cancellation apply.
Existing v1 APIs and opt-in `codex_run` behavior remain unchanged.

A native Luna bug-fix round repaired current release-reference synchronization
in README while preserving historical version records. Independent Sol QA
routed an LF/CRLF regression back for correction; the resulting two-case
real-script fixture and full local lint pass. This local proof does not close
Ubuntu/package acceptance or establish total-token savings.

See the [native workflow guide](../harness/NATIVE_WORKFLOW.md) and
[milestone contract](../harness/contracts/v1.38-native-workflow.md).
Durable resume, context fingerprints, model capability verification and stronger
machine-enforced QA receipts remain in their later roadmap milestones.

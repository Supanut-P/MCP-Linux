# v1.42.0 durable caller-native workflow state

Status: milestone verification closed after independent implementation and
closure QA. Local, Ubuntu/package, old-binary rollback and installed recovery
passed. The configured VM runs accepted 1.42.0. Publication is unapproved.
See the [closure receipt](../harness/evidence/2026-10-03-v1.42-ubuntu.md).

The additive `workflow` surface persists immutable task DAGs in SQLite,
atomically claims ready tasks, records ordered events and bounded checkpoints,
and restores status after reopen or transport reconnect. It never dispatches
execution automatically, resets completed tasks or transfers active claims.
Current permission checks and registered path validation protect coordination;
actual execution retains separate policy and confirmation checks.

Completion and evidence references remain caller-reported. Coordination cancel
does not stop a native process; the caller separately cancels its owned worker.
Single-user stable actor ownership is not team RBAC. File locks and source-bound
QA are later milestones. See the [contract](../harness/contracts/v1.42-durable-workflow.md)
and [caller guide](../harness/DURABLE_WORKFLOW.md).

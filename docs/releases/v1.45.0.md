Add a local evidence importer and report API for six source-matched
single-agent/routed benchmark pairs. The packaged launcher provides
`benchmark-workflow --evidence-dir PATH`. Reports bind source, acceptance,
context and log fingerprints without running a task or reading workflow state.
Existing MCP tools and v1 invocation contracts remain compatible.

Reports keep failures and missing calls, expose observed subtotals separately
from complete token totals, and never convert context bytes into estimated
tokens. Cached input and reasoning output are subsets. Incomplete or unfinished
logs cannot satisfy the experimental 25% goal. Caller outcomes and identities,
requested models, timing and log completeness retain their attestation boundary.

Native Windows response fixtures are microbenchmarks, not general coding,
incident or recovery execution proof. Linux native provider readiness remains a
separate v2 gate. Seven-day soak is waived. See the
[measured native comparison](../harness/evidence/2026-10-03-v1.45-native-benchmark.md),
[caller guide](../harness/USAGE_BENCHMARK.md) and
[contract](../harness/contracts/v1.45-usage-benchmark.md).

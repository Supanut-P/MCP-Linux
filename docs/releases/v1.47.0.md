# v1.47.0: Durable incident workspace

Implementation and Ubuntu/package verification are closed after independent QA
under the [receipt](../harness/evidence/2026-10-03-v1.47-ubuntu.md). Installed
STDIO/HTTP, package lifecycle and native connector restart checks passed.
Publication remains unapproved.

Collect combines fixed registered-host reads, local numeric metrics and watcher
metadata into bounded, hashed, paged evidence. Repeating a caller-known incident
ID never replays probes. Partial observations survive restart; expired collection
projects interrupted. A single deadline includes registration reads. Changed
mapping workspaces cannot become fresh probe authority.

Journal text, provider errors, credentials and raw watcher paths are omitted.
Reports distinguish retained observations, missing sources and current binding
drift. Complete state must agree with retained evidence. Quotas and strict
corruption checks bound SQLite state without automatic deletion.

See the [contract](../harness/contracts/v1.47-incident-workspace.md) and
[caller guide](../harness/INCIDENT_WORKSPACE.md). v1 interfaces remain additive.
Hashes verify bytes, not provider truth; ownership is not tenant authentication.
Linux native provider readiness is a separate final v2 gate. Seven-day soak is
waived, not passed.

# v1.56.0 release candidate

Adds a deterministic Linux sandbox usability preflight before enhanced Codex
model dispatch. A failed helper, timeout, cancellation or unverifiable owned
process cleanup rejects dispatch. Legacy Codex invocation stays unchanged.
The no-op probe does not establish filesystem or network containment.

Native acceptance uses an isolated subscription-authenticated CLI on the
approved Ubuntu test VM. The pinned CLI requires a temporary scoped AppArmor
profile in this lab; it is unloaded after each test and no system-wide user
namespace restriction is disabled. Filesystem/network canaries are separate
evidence. The default 6.1 model was unavailable to this account; explicit 5.6
selection worked, with no silent fallback.

Release status remains open pending candidate-bound Ubuntu/package acceptance,
native workflow checks, benchmark results and independent closure review.
Earlier failed native/benchmark attempts remain part of the evidence. Token
reduction is an experimental objective, not an established saving. Seven-day
soak remains waived; publication requires human approval.
